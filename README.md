# Banking System — ItGrind

Учебный проект банковской системы на Python.

## Описание
Проект разработан в рамках курса по объектно-ориентированному
программированию (ООП).

Всего предусмотрено 7 этапов разработки и финальная интеграция.

## Day 1 — Базовые банковские счета

Реализованы:
- Абстрактный класс AbstractAccount
- Класс BankAccount
- Статусы ACTIVE, FROZEN, CLOSED
- Пополнение и снятие средств
- Проверка баланса
- Генерация идентификаторов счетов
- Поддержка RUB, USD, EUR, KZT, CNY
- Собственные классы исключений
- Автоматические тесты

## Day 2 - Продвинутые типы банковских счетов

Реализованы:
- Класс SavingsAccount - сберегательный счёт
- Класс PremiumAccount - премиальный счёт
- Класс InvestmentAccount - инвестиционный счёт
- Минимальный остаток и начисление месячных процентов
- Повышенные лимиты снятия средств
- Возможность овердрафта и фиксированные комиссии
- Инвестиционный портфель с активами stocks, bonds, etf
- Инвестирование и возврат средств из портфеля
- Расчёт прогнозируемой годовой доходности
- Переопределение методов withdraw(), get_account_info(), __str__()
- Реализация наследования и полиморфизма
- Валидация операций и обработка исключений
- Автоматические тесты (всего 36 успешно пройденных проверок)

## Технологии
- Python 3.13
- ABC
- Enum
- Decimal
- UUID
- Pytest

## Запуск проекта

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

Запуск программы:

```bash
python main.py
```

Запуск тестов:

```bash
python -m pytest -v
```
