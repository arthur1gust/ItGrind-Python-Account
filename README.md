# Banking System — ItGrind

Учебный проект банковской системы на Python.

## Описание
Проект разработан в рамках курса по объектно-ориентированному
программированию (ООП).

Всего предусмотрено 7 этапов разработки и финальная интеграция.

## Day 1 — Базовые банковские счета

Реализованы:
- Абстрактный класс AbstractAccount
- Класс BankAccount
- Статусы ACTIVE, FROZEN, CLOSED
- Пополнение и снятие средств
- Проверка баланса
- Генерация идентификаторов счетов
- Поддержка RUB, USD, EUR, KZT, CNY
- Собственные классы исключений
- Автоматические тесты

## Технологии
- Python 3.13
- ABC
- Enum
- Decimal
- UUID
- Pytest

## Запуск проекта

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

Запуск программы:

```bash
python main.py
```

Запуск тестов:

```bash
python -m pytest -v
```
